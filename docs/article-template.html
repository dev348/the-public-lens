THE PUBLIC LENS · Article template / लेख नमुना

How to use: File → Make a copy (keep it in this folder). Fill in the table, write your article below it, then change Status to Publish. The website updates within about 15 minutes. To take an article down, change Status back to Draft.

वापर: File → Make a copy. तक्ता भरा, खाली लेख लिहा आणि Status मध्ये Publish लिहा. सुमारे १५ मिनिटांत लेख वेबसाइटवर येईल.

Tips: use Heading 2 for subheadings · bold, italic and links work · photos: Insert → Image (choose "In line") · a pull quote = an indented paragraph (Format → Align & indent → Increase indent) · footnotes: Insert → Footnote · keep everything in one tab.
